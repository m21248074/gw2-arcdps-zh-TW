# 術語表

`scripts/check.py` 會依 `docs/glossary.tsv` 檢查「應避免的寫法」(大陸用語、錯字、拼寫不一致),`--fix` 可自動套用。
下表是目前譯文實際採用的詞,以及還沒決定的項目。

## 已採用

| 英文 | 譯法 | 備註 |
|---|---|---|
| squad | 團隊 | 例:團隊統計、團隊日誌 |
| subgroup | 小隊 | 例:小隊顏色、置頂小隊 |
| party | 隊伍 | 只出現在 364、768 |
| window | 視窗 | ArcDPS 的視窗一律稱視窗;遊戲本身的面板(1328、1329)稱面板 |
| scroll / rolling | 捲動 / 滾動 | 畫面捲動用「捲動」;rolling(滾動式統計區間)用「滾動」 |
| condition | 症狀 | 與官方遊戲用語是否一致尚未確認,見下方待決定 |
| barrier | 屏障 | |
| defiance | 蔑視 | 例:蔑視條、CC 蔑視量 |
| crowd control | CC | 例:CC 次數、CC 時長 |
| minion | 召喚物 | |
| cleanse | 清除症狀 | 不與 strip 混用 |
| revival | 復活 | 743、744 已與 1115、1116 對齊(原為「救人」) |
| log(名詞) | 日誌 | 動詞或「紀錄行為」用「記錄」;「紀錄」一律寫「記錄」 |
| style | 樣式 | |
| filter | 篩選 | |
| extension | 擴充插件 | |
| Buff(英文拼寫) | Buff | 與中文之間留一個空格,例:Buff 視窗 |

## 待決定

| 項目 | 現況 | 建議 |
|---|---|---|
| Buff 與 增益 | 「Buff」約 19 處(多為視窗與選項名),「增益」約 26 處(多為統計項目) | 統一成「增益」較符合遊戲內說法;保留「Buff」也可,但要二選一 |
| strip | 「拔增益」6 處、「移除增益」5 處並用 | 統一成「拔增益」(較新的條目都這樣用) |
| 症狀 與 狀態 | 症狀 9 處、狀態 2 處 | 需對照遊戲內 condition 的繁中名稱 |
| 數據 / 資料 / 統計 | 數據 12、資料 4、統計 32 | 暫時維持,語境不同 |
| 插件 / 外掛 | 插件 11、擴充插件 9、外掛 1 | 「插件」單獨出現的地方可改成「擴充插件」 |
| 重啟 / 重新啟動 | 重啟 4、重新啟動 3 | 擇一 |
| 職業 與 專業 | 職業 7、專業 3 | 「專業特化」是遊戲用語(elite specialization),其餘用「職業」,基本合理 |
